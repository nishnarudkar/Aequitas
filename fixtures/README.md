## 🚀 How to Use for Testing

1. Open Aequitas at **[http://localhost:3000](http://localhost:3000)**.
2. Select the matching persona tile on the intake page.
3. Choose the **"Paste Text"** tab.
4. Open any `.txt` file above, copy its entire contents, and paste it into the text box.
5. Click **"Start Analysis"** to inspect plain-language summary, risk cards, Q&A, checklist, and printable brief outputs.
